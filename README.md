# Shopping Cart

A shopping cart built with HTML, CSS, Bootstrap and vanilla JavaScript (DOM events).

## Features
- Increase or decrease the quantity of each item with the + and − buttons
- Delete an item from the cart
- Like an item with a heart button that changes color
- Total price updates automatically with quantity changes and deletions

## Run it
Open the folder in VS Code and run `index.html` with the Live Server extension.

## Project structure
- `index.html`: page markup
- `style/style.css`: styles
- `js/script.js`: cart logic
- `assets/`: product images
